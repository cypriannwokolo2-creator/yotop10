# The Flywheel

*Why it grows itself — the business in plain terms.*

Content platforms live or die on one loop: readers arrive, some become contributors, their contributions attract more readers. YoTop10 shortens every link in that loop.

**Arrival is free.** Search engines index every list, debate, article, category, and profile — a living sitemap refreshed every few minutes, social preview cards generated per page, instant indexing pings on every publish. Each ranking is link-bait by construction: people share lists to argue with them.

**Conversion is instant.** The sixty-second path from first visit to first submission (Chapter 2) means the platform harvests contributions from traffic that any other site would merely count.

**Quality compounds.** Human review keeps the front page worth visiting. Counter-lists and debates turn single posts into self-renewing arguments — one good list spawns its rebuttal, which spawns votes, which draw the original author's defenders back. Every dispute is free content.

**Costs stay flat.** The entire platform runs on commodity open-source software (next chapter) on a single virtual server. There is no per-user cost curve: anonymous contributors need no email infrastructure, no password-reset support desk, no identity-verification vendor. Moderation is the only scaling cost, and it grows sub-linearly because automation triages before humans look.

**Revenue: deliberately later.** The platform is pre-revenue by design — the current phase is audience and catalog, not monetization. The inventory being built (ranked, categorized, sourced evergreen content) is the asset against which advertising, sponsorship, or premium features will eventually sell. No revenue has been booked to date.
